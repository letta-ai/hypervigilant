# Vault conventions

This small vault keeps durable concepts and active projects together.

- Every note starts with `type` and `status` frontmatter.
- A wikilink names an existing note. Search before changing an ambiguous link.
- A project note has `## Status` and `## Next step` sections.
- A plan, a source change, and a verified external result are different facts.
- Mechanical repairs may be applied directly. Interpretive changes remain findings for the author.
